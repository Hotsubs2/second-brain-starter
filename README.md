# Second Brain Starter

A notebook that backs itself up, and the rules any AI follows when it works for you.

**Looking at the template?** Click **Use this template → Create a new repository**. Name it `<yourfirstname>-second-brain`, make it **Private**, create it. That is the whole build.

**Is this your copy?** Open the folder in Obsidian and start at `Home.md`. The first-time checklist is `System/Start Here.md`.

- Rules for any AI: `AGENTS.md`
- How everything works, in plain English: `System/How This Works.md`
- How a new project repository is made: `System/New Project Recipe.md`
- The prompts you paste into any AI: `System/Prompts.md`

Nothing secret and nothing private about other people goes in here. `private/` stays on your computer.
