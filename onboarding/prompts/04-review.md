# Understand the contribution

Explain this contribution or pull request to me: [paste its link or the draft]. I want to understand its value and consequences before using it.

Read the actual available content. If you cannot access it, ask for the relevant text instead of guessing from its title.

Tell me briefly:
1. What useful work it accomplishes for my stated project.
2. Which parts come from my sources, which are your inferences, and which I need to check.
3. What would change if I save or merge it, including any unrelated changes.
4. Whether it stays within the authorized scope and repository rules.
5. What remains uncertain and what you recommend I do next, with a reason.

Do not merge, edit, comment, send, or publish anything. An explanation is not an independent guarantee that the work is correct.
